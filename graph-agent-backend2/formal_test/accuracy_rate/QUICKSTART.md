# Agent Gremlin 执行准确率测试 - 快速开始（SSE 版本）

## 测试目标

验证 Agent 从自然语言问题生成 Gremlin 查询的能力，并检查生成的查询是否能成功执行。

**本版本使用 SSE 流式接口通信，完全模拟真实前端调用场景。**

## 快速开始

### 1. 确保前置条件

```bash
# 确认已生成测试数据
ls formal_test/ground_truth_answers.json

# 确认数据库正在运行
# 检查 .env 配置文件中的数据库连接参数
```

### 2. 启动后端服务

```bash
# 在项目根目录启动后端服务
python run.py
```

等待看到类似输出：
```
✅ HugeGraph连接成功
✅ LLM客户端初始化完成
* Running on http://127.0.0.1:5000
```

### 3. 运行测试

**打开新的终端窗口**，在项目根目录执行：

```bash
python formal_test/accuracy_rate/test_agent_gremlin_execution_sse.py
```

### 4. 查看结果

测试完成后会生成两个文件：

- **JSON 报告**: `formal_test/accuracy_rate/agent_gremlin_execution_results_simple_sse.json`
  - 包含所有测试用例的详细结果
  
- **文本摘要**: `formal_test/accuracy_rate/agent_execution_summary_simple_sse.txt`
  - 易读的统计信息和失败详情

## 测试流程

```
自然语言问题 
    ↓
HTTP POST 请求到 SSE 接口
    ↓
后端 Agent 处理（流式返回推理步骤）
    ↓
解析 final_answer 事件
    ↓
提取 "gremlin语句" 字段
    ↓
执行 Gremlin 查询
    ↓
验证是否成功执行
    ↓
统计通过率
```

## 故障排查

### 问题1: 无法连接到后端服务

**错误信息**: `❌ 无法连接到后端服务，请先启动后端`

**解决方案**:
```bash
# 确保在项目根目录启动
cd d:\Code\graph-agent-project\graph-agent-backend2
python run.py
```

### 问题2: API 调用超时

**错误信息**: `请求超时`

**解决方案**:
1. 检查 LLM API 是否正常
2. 增加脚本中的超时时间（修改 `timeout=120` 为更大值）
3. 检查网络连接

### 问题3: 无法提取 Gremlin 语句

**可能原因**:
- Agent 没有按照指定格式返回答案
- JSON 格式不正确

**解决方案**:
1. 查看文本报告中的 `final_answer` 内容
2. 检查 Agent 的 Prompt 配置
3. 确认 `prompts.py` 中的返回格式要求

### 问题4: Gremlin 执行失败

**可能原因**:
- Agent 生成的 Gremlin 语法错误
- 数据库中不存在对应的 Schema
- HugeGraph 索引限制

**解决方案**:
1. 查看文本报告中的错误信息
2. 对比预期 Gremlin 和实际提取的 Gremlin
3. 检查数据库 Schema 和数据

查看详细错误信息请查看生成的文本报告文件。
