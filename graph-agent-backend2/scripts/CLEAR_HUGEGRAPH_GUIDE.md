# HugeGraph 图清空工具使用指南

## 功能说明
`clear_hugegraph.py` 脚本用于**完全清空**指定的 HugeGraph 图，包括：
- ✅ 删除所有顶点数据
- ✅ 删除所有边数据  
- ✅ 删除所有顶点标签（Vertex Labels）
- ✅ 删除所有边标签（Edge Labels）
- ✅ 删除所有属性键（Property Keys）

执行完成后，您将得到一个**完全空白的图**，可以重新开始导入新的数据集。

## 使用方法

### 1. 基本使用
```bash
python scripts/clear_hugegraph.py
```

### 2. 脚本执行流程
1. **连接验证**: 自动连接到配置的 HugeGraph 实例
2. **安全确认**: 要求用户输入 `yes` 确认操作（防止误操作）
3. **数据删除**: 
   - 首先删除所有边（`g.E().drop()`）
   - 然后删除所有顶点（`g.V().drop()`）
4. **Schema 清理**:
   - 按正确顺序删除边标签 → 顶点标签 → 属性键
   - 使用 PyHugeGraph 原生 API 确保删除成功
5. **结果验证**: 显示最终的图状态确认清理完成

### 3. 配置说明
脚本会自动读取项目中的 `.env` 配置文件，使用以下环境变量：
- `HUGEGRAPH_HOST`: HugeGraph 服务器地址
- `HUGEGRAPH_PORT`: HugeGraph 服务器端口  
- `HUGEGRAPH_GRAPH`: 要清空的图名称
- `HUGEGRAPH_USER` / `HUGEGRAPH_PWD`: 认证信息（如果需要）

### 4. 安全特性
- 🔒 **强制确认**: 必须输入 `yes` 才会执行删除操作
- 📊 **进度显示**: 实时显示每个步骤的执行状态
- ✅ **结果验证**: 执行完成后验证清理结果
- ⚠️ **错误处理**: 单个元素删除失败不会影响整体流程

### 5. 典型使用场景
- **测试环境重置**: 在导入新数据集前清空现有数据
- **开发调试**: 快速获得干净的图环境进行测试
- **数据迁移**: 准备全新的图结构重新开始

### 6. 注意事项
- ⚠️ **不可逆操作**: 删除的数据和 Schema 无法恢复
- ⚠️ **权限要求**: 需要对目标图有完整的管理权限
- ⚠️ **服务可用**: 确保 HugeGraph Server 正在运行
- ⚠️ **并发影响**: 清空操作期间避免其他进程访问该图

## 故障排除

### 常见问题
1. **连接失败**: 检查 `.env` 配置和 HugeGraph Server 状态
2. **权限不足**: 确认用户有 Schema 管理权限
3. **删除失败**: 某些 Schema 元素可能被其他元素引用，脚本会显示具体错误

### 手动清理（备用方案）
如果脚本执行失败，可以手动执行 Gremlin 命令：
```gremlin
// 删除所有数据
g.E().drop()
g.V().drop()

// 然后通过 HugeGraph Studio 或 REST API 删除 Schema
```

---
**提示**: 建议在执行此脚本前，先备份重要的数据或 Schema 定义！
